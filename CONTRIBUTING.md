# Contributing to celladore

Thanks for your interest in contributing! This file is the org-wide default — individual repos may override it with their own `CONTRIBUTING.md`.

## Before you start

- Check open issues and PRs to avoid duplicate work.
- For anything non-trivial, open an issue first to discuss the approach.

## Making changes

1. Fork the repo (or branch, if you have write access).
2. Create a feature branch off `main` — don't commit directly to `main`.
3. Keep commits focused; write clear commit messages ([Conventional Commits](https://www.conventionalcommits.org/) preferred).
4. Add or update tests for behavior changes.
5. Open a pull request against `main` and fill in the PR template.

## Code review

- PRs need at least one approval before merge.
- CI must pass (where configured) before merge.
- Be responsive to review feedback — if you disagree, say why rather than going silent.

## Reporting bugs / requesting features

Use the issue templates in this repo — they apply across all `celladore` repos that don't have their own.

## Security issues

Do **not** open a public issue for a security vulnerability. See [SECURITY.md](./SECURITY.md).

# .github

Org-wide defaults for [`celladore`](https://github.com/celladore):

- **`profile/README.md`** — the public org profile shown at [github.com/celladore](https://github.com/celladore)
- **`CONTRIBUTING.md`**, **`SECURITY.md`**, **`PULL_REQUEST_TEMPLATE.md`**, **`ISSUE_TEMPLATE/`** — fallback community health files, automatically inherited by any repo in the org that doesn't define its own

See [celladore-org](https://github.com/celladore/celladore-org) for the internal project index and roadmap.
